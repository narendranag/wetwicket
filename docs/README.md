# Wet Wicket documentation

Wet Wicket is a loving exploration of cricket, by cricket lovers, for cricket lovers: data explorations, breakdowns of epic matches, browser games, essays and tools, with an archive of every match in Cricsheet. Live at <https://wetwicket.com>. How the code is built and run is in `CLAUDE.md` at the repo root; this folder is about what the site is.

## Reading order

| Document                                                      | What it covers                                                                               | Audience |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | -------- |
| [01 Information architecture](01-information-architecture.md) | Principles, sections, URLs, the Archive, the content model, the front page, the first series | Everyone |

Hand-offs between sessions are kept beside these documents, dated: [GA4 + Tag Manager go-live (2026-10-04)](HANDOFF-2026-10-04-analytics.md).

## Terms used throughout

| Term        | Meaning                                                                                                                      |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Piece       | One published item — an essay, a data story, a game or a tool — signed by its author, with a permanent URL under its section |
| Section     | Where a piece lives, with a vernacular name: The Numbers, Classics, The Nets, The Long Room, Scorebook, The Archive          |
| Series      | An ordered set of pieces on one theme, such as Rain Rules; it orders pieces but doesn't own their URLs                       |
| The Archive | The match, player, competition and ground pages, served from D1 and covering everything in Cricsheet                         |
| Cricsheet   | The source of all match data (Stephen Rushe, ODC Attribution License 1.0), credited on every page that uses it               |

## Ways to read these documents

| For              | Use                                                                                                               |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| People           | [`index.html`](index.html): all documents in one static page. Open it in a browser; it needs no server.           |
| Agents and tools | [`llms.txt`](llms.txt) for the index, then the Markdown files. [`AGENTS.md`](AGENTS.md) explains the conventions. |
| Programs         | [`data/manifest.json`](data/manifest.json), [`data/glossary.json`](data/glossary.json)                            |

The Markdown files are the source of truth. `index.html`, `llms.txt` and everything under `data/` are generated by `docs-build`.
